# Personal Finance Tracker

Консольное приложение на Python для учёта доходов и расходов.

## Возможности

- добавление доходов и расходов;
- категории и описания операций;
- автоматическая дата создания;
- просмотр истории;
- расчёт баланса;
- общая статистика;
- отчёт по категориям;
- фильтрация операций;
- сортировка по дате и сумме;
- отчёт за выбранный месяц;
- редактирование операций;
- удаление операций;
- сохранение данных в JSON;
- автоматические тесты.
